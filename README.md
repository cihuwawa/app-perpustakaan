# App Perpustakaan

## Deskripsi

App Perpustakaan adalah aplikasi berbasis Laravel 12 yang digunakan untuk membantu pengelolaan data perpustakaan. Project ini dikembangkan sebagai bagian dari praktikum Pemrograman Framework.

## Menjalankan Project Secara Lokal

1. Pastikan PHP, Composer, dan MySQL sudah terinstal.
2. Clone repository:
   ```bash
   git clone https://github.com/chihuwawa/app-perpustakaan.git
